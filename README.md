# Protege tu vida digital

Micrositio interactivo de sensibilización sobre seguridad digital. Incluye un quiz, un carrusel informativo, una infografía y un formulario de comentarios integrado.

## Desarrollo local

```bash
npm install
npm run dev
```

## Publicación

El flujo de GitHub Actions incluido compila y publica automáticamente el sitio en GitHub Pages al enviar cambios a la rama `main`.
